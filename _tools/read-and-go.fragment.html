SECTION A · Predict-the-output SAs — ≈ 24 marks
A1 · MaxAbsScaler min/max 2 marks

Trigger: MaxAbsScaler().fit_transform(data) then print(min/max).

  1. Find the biggest absolute value M in the data. Divide rule: scaled = x ÷ M
  2. For min: take the most negative x → x ÷ M. For max: biggest x → x ÷ M.
  3. Example: [-3, 0, -2, 2, -1, -4] → M = 4 → min = -4 ÷ 4.
min = -1.0 · (sister variant max = 0.5)

A2 · SimpleImputer mean 2 marks

Trigger: SimpleImputer(strategy="mean") + statistics_, or "compute the missing value".

  1. Cross out every nan. Average the survivors.
  2. [1, 2, 3, nan, 4, nan, 5] → (1+2+3+4+5) ÷ 5.
  3. Column F3 [9, 7, ?, 5] → (9+7+5) ÷ 3.
3.0 · F3 missing = 7.0

A3 · KNN predict — count the 3 nearest 3 marks

Trigger: KNeighborsClassifier(n_neighbors=k) + predict(test).

  1. Distance from test point to EVERY train point (ordinary straight-line distance).
  2. Circle the k smallest. Read their labels.
  3. Majority wins. Tie → smaller label wins.
  4. Example: test [8,9], k=3 → nearest are [10,11]❶ [5,6]❶ [2,3]⓿ → votes 1,1,0.

A5 · f1_score from two lists ⚠️ trap 2–3 marks

Trigger: f1_score(y_true, y_pred) with written-out lists.

  1. TP = positions where both are 1. FP = pred-1-but-true-0. FN = true-1-but-pred-0.
  2. Precision = TP ÷ (TP+FP). Recall = TP ÷ (TP+FN).
  3. F1 = 2·P·R ÷ (P+R).
  4. Lists [1,1,0,1,0,0,1,0,1] vs [0,1,0,1,0,1,1,1,1] → TP=4, FP=2, FN=1 → P=4/6, R=4/5 → F1 = 0.7273.
MCQ version → tick 0.72 (nearest option!) · SA version → write 0.73

📌 Repeat offender. Same drill: recall pair → 0.75.

A6 · StandardScaler / MinMax transform a new point 2 marks

Trigger: fit scaler on a column, transform([[8]]).

  1. Standard: mean μ, spread σ of the column → z = (x − μ) ÷ σ. [2,6,10,14]: μ = 8 → z = 0.
  2. MinMax: (x − min) ÷ (max − min) → (8−2) ÷ (14−2) = 0.5.
Standard → 0.0 · MinMax → 0.5

A8 · DummyRegressor MSE 3 marks

Trigger: DummyRegressor(strategy='mean') + mean_squared_error.

  1. Dummy predicts the TRAIN mean for everything: [10,15,20,25,30] → 20.
  2. MSE = average of (test − 20)²: ((35−20)² + (40−20)²) ÷ 2 = (225+400) ÷ 2.

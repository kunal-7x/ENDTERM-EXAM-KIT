⚡ BA EXAM-DAY CHEAT (the 6 moves that cover 80%)

  1. See "HCU" → HCU = Σ(λ × ref_output) ÷ efficiency. (BA-03)
  2. See confusion/table with Predicted vs Actual → count TP/FP/TN/FN from the table, then accuracy/precision/recall. (BA-02)
  3. See "expected frequency" + rows×cols table → E = row_total × col_total ÷ grand_total; df = (r-1)(c-1). (BA-01)
  4. See demand D = a − bP → revenue-max P = a/2b; profit-max P = (a/b + cost)/2. (BA-02)
  5. See "efficiency of DMU" → efficiency = weighted outputs ÷ weighted inputs; efficient ⟺ equals 1. Reference units = non-zero dual variables. (BA-03)
  6. See P(defective | factory-type story) → total probability then Bayes flip. (BA-01)

15 formulas · reference

Formula sheet

These cover essentially every hand-computed question in the past papers. Learn to apply each in under 60 seconds.

Standardisation — StandardScaler

z = x − μσ

σ uses n in the denominator, not n−1. NumPy's default std() matches it; pandas' does not.

Min–Max and MaxAbs scaling

x′ = x − xmin xmax − xmin x′ = x|x|max

Min–Max lands in [0, 1]. MaxAbs lands in [−1, 1] and leaves zeros at zero, so it is the sparse-data choice.

Regression errors

MSE = 1n n∑i=1 (yi − ŷi)2 MAE = 1n n∑i=1 |yi − ŷi|

RMSE is √MSE. sklearn reports these as negative values in cross_val_score, because it always maximises.

Coefficient of determination

R2 = 1 − SSresSStot = 1 − ∑(yi − ŷi)2∑(yi − ȳ)2

Range is −∞ to 1, never bounded below by 0. Negative means worse than predicting the mean. Asked repeatedly.

Regularised linear models

Ridge: ‖Xw − y‖2 + α‖w‖22 Lasso: 12n ‖Xw − y‖2 + α‖w‖1

Higher α → smaller coefficients and more underfitting. Only Lasso (L1) drives coefficients exactly to zero.

Normal equation

w = (XTX)−1 XTy

What LinearRegression solves in closed form. Cost grows with the cube of feature count, so SGDRegressor takes over on wide data.

Confusion matrix counts

Precision = TPTP + FP Recall = TPTP + FN Accuracy = TP + TNTP + TN + FP + FN

sklearn prints the matrix with true labels down the rows and predicted across the columns, in sorted label order.

F1 and F-beta

F1 = 2 · P · RP + R Fβ = (1 + β2) P · Rβ2P + R

β > 1 weights recall more. F1 is the harmonic mean, so it collapses toward whichever of P or R is worse.

Impurity for decision trees

Gini = 1 − k∑i=1 pi2 Entropy = −k∑i=1 pi log2 pi

Both peak on a 50/50 split — Gini at 0.5, entropy at 1.0 — and hit 0 on a pure node. Gini is the default because it skips the log.

Information gain

IG = I(parent) − ∑j njn I(childj)

Weight each child by its share of samples. The tree picks the split with the largest gain.

Logistic and softmax

σ(z) = 11 + e−z pk = ezk∑j ezj

Log loss for one sample: −[y log p + (1−y) log(1−p)]. Softmax needs lbfgs, sag, saga or newton-cg — never liblinear.

Distance and similarity

deuc = √∑(ai − bi)2 cos = a · b‖a‖ ‖b‖

Manhattan is ∑|aᵢ − bᵢ|. Cosine ignores magnitude entirely, which is why it is the default for text vectors.

K-Means objective and silhouette

Inertia = ∑i ‖xi − μc(i)‖2 s = b − amax(a, b)

Inertia always falls as k rises, so it can't pick k alone — that's the elbow method. Silhouette runs −1 to 1.

AdaBoost weights

αt = 12 ln 1 − εtεt

ε is the weighted error of stump t. Misclassified samples get their weight multiplied by eα before the next round.

TF-IDF as sklearn computes it

idf(t) = ln 1 + n1 + df( t) + 1

That is the smooth_idf=True default. The trailing +1 means a term in every document gets idf = 1, not zero. Rows are L2-normalised afterwards.
